# Contributing

Contributions are welcome.

1. Fork the repository and create a focused branch.
2. Keep the app dependency-free and compatible with modern browsers.
3. Preserve the existing visual structure unless the change intentionally updates it.
4. Test the periodic-table layout, element filters, detail panel, and PNG export at desktop and mobile widths.
5. Submit a pull request describing the change and validation performed.

For scientific or technical corrections, include the applicable validated method or authoritative reference.
